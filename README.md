# 🛒 Shopping List App

*Shopping List App* is a lightweight and intuitive React + Vite-powered application that allows users to manage a personal or inventory-style shopping list. Add, check off, and remove items with ease — great for learning and real-world utility alike.

---

## 🎯 Purpose

This app was developed for both educational purposes and practical use.  
It enables users to maintain a clear, interactive shopping list or manage simple inventory tracking in the browser.

---

## 🧩 App Architecture

Built using modern React with Vite for fast development and clean structure:

| 🧱 Component      | 📌 Description                              |
|------------------|---------------------------------------------|
| *App*            | Root container component                    |
| *ItemList*       | Renders and manages the list of items       |
| *ItemForm*       | Handles item input and submission           |
| *Item*           | Displays individual items with actions      |
| *Hooks/State*    | Local state management with useState/useEffect |

---

## 🚀 Features

<ul>
  <li>➕ <strong>Add Items</strong>: Quickly add new shopping list entries.</li>
  <li>✅ <strong>Check Off Items</strong>: Mark items as completed.</li>
  <li>🗑️ <strong>Delete Items</strong>: Remove items from your list anytime.</li>
</ul>

## 📦 Installation

### Prerequisites

•⁠  ⁠Node.js (v16 or later)  
•⁠  ⁠npm or yarn

### Steps

```bash
# Clone the repository
git clone https://github.com/bsaltalii/shopping-list-app.git

# Navigate to the project directory
cd shopping-list-app

# Install dependencies
npm install

# Start the development server
npm run dev
```
